ONE-TIME SETUP
1. Go to supabase.com, make a free account and a new project.
2. SQL Editor -> run this:
     create table snapshot (id int primary key, data jsonb not null);
     alter table snapshot enable row level security;
     create policy "public read" on snapshot for select using (true);
   (Only reading is public. Nobody can write without your secret key.)
3. Project Settings -> API. Copy:
     Project URL + "anon" key   -> put in index.html (SUPA = {...})   [safe to be public]
     "service_role" key         -> put in sync.py ONLY                [SECRET, never upload to GitHub]
4. Upload to GitHub Pages: index.html and the static/ folder ONLY (not sync.py / server.py / README).

RUNNING IT
On your PC (while the Minecraft server is on):  python3 sync.py
Edit DB path in sync.py (or set STATS_DB) to the plugin's real stats.db.
It checks every 10s and only uploads when something changed. The website updates live.
Also edit the CFG block in index.html (server IP, rank names).

DISCORD LOGIN + STORE (new)
1. discord.com/developers/applications -> open your AzurPvP bot's application.
2. General Information -> copy "Application ID" -> paste into index.html as CFG.clientId.
3. OAuth2 -> Redirects -> Add Redirect -> the exact address of your site, e.g.
     https://yourname.github.io/azurpvp/      (must match exactly, including the trailing slash)
   For local testing with server.py also add http://localhost:8080/
4. Store: set CFG.ticketUrl to your Discord tickets channel link (optional, falls back to CFG.discord).
   Prices are in CFG.prices. Only the "identify" scope is requested, no secret is needed on the site.

AUTOMATIC TICKETS (bot update)
The updated azurpvp_bot.py now runs a small order API. When set up, "Place order" on the site opens a ticket in Discord
for staff automatically (buyer is verified through their Discord login).
1. Put the new azurpvp_bot.py on your bot host and restart it. It listens on port 8081 (AZURPVP_STORE_PORT to change).
2. Set AZURPVP_GUILD_ID (already used by /link) and AZURPVP_SITE_ORIGIN=https://your-site-address
3. Expose the port over HTTPS (Cloudflare Tunnel, Caddy, nginx). An https site cannot call a plain http address.
4. In index.html set CFG.orderApi to  https://your-api-address/api/order
If orderApi is empty or the API is down, the site falls back to the copy-and-paste order summary.


WEBSITE LOGIN ROLE (bot API)
- Set AZURPVP_SITE_ORIGIN to the website origin (for GitHub Pages, scheme + host only; no repository path).
- Set AZURPVP_GUILD_ID to the Discord server ID.
- Expose the bot's AZURPVP_SITE_LOGIN_PORT (default 8082) behind HTTPS.
- Set CFG.loginApi in index.html to that public HTTPS URL ending in /api/site-login.
- Set CFG.clientId and register the site's exact URL as an OAuth2 redirect in the Discord Developer Portal.
- The bot verifies the OAuth token with Discord before granting role 1562471521862295562 and posting in channel 1562471749550088322.
